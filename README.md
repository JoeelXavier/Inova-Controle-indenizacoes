# Inova-Indeniza-es
Com o objetivo de organizar e automatizar um fluxo pagamentos para clientes, o projeto cria um ecossistema organizado e contínuo. Com fluxo de aprovações, auditoria e painel de monitoramento atualizados automaticamente o projeto otimizou e reduziu o tempo de trabalho de 4 setores com um sistema seguro e controlado.
